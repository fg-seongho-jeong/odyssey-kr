# odyssey-kr

CGV 예매 오픈과 "괜찮은 자리" 발생을 감시해 텔레그램으로 알려주는 봇.
기본값은 **CGV 용산아이파크몰 IMAX관, '오디세이'** 이지만 `config.yaml`만 바꾸면
다른 영화/극장/상영관도 감시할 수 있다.

영화/상영관/극장은 `config.yaml`에서 전역으로 공유하지만, **감시할 날짜 범위와
시간대는 구독자마다 다르게 설정**할 수 있다. 봇에게 메시지를 보내면(또는 `/start`)
날짜/시간을 순서대로 물어보는 대화형 흐름으로 자기만의 조건을 등록한다.

## 동작 원리

CGV(cgv.co.kr)는 Cloudflare 봇 차단이 걸려 있는데, 이게 TLS 지문(JA3) 레벨 차단이라
`requests`/`curl`로 헤더를 아무리 브라우저처럼 꾸며도 403이 돌아온다.
이 프로젝트는 [`curl_cffi`](https://github.com/lexiforest/curl_cffi)로 Chrome의 TLS 지문을
그대로 흉내내 우회한다. (`cgv.py` 참고)

핵심 API는 `GET /api/v1/booking/searchMovScnInfo?coCd=A420&siteNo=<극장코드>&scnYmd=<날짜>&rtctlScopCd=08`
하나다. 이걸 날짜별로 호출해 상영 스케줄 전체를 받아온 뒤, 영화명/상영관명이 맞는 회차 중
구독자 각자의 날짜/시간대 조건에 맞고 잔여 좌석(`frSeatCnt`)이 있는 것을 찾아 그 구독자에게만 알린다.

감시해야 할 날짜는 **전체 구독자의 날짜 범위를 합친 뒤** tick마다 하루씩 순환 조회하므로,
구독자가 늘거나 개별 범위가 넓어져도 요청 속도는 항상 `interval_seconds`(기본 1초 + 지터)로
고정된다. 대신 감시 날짜 폭이 넓어질수록 특정 날짜 하나가 다시 확인되기까지의 간격은 길어진다
(예: 서로 다른 30일이 걸려 있으면 각 날짜는 대략 30초에 한 번씩만 확인됨).

### "괜찮은 자리(중간 블록)" 판정은 근사치다

CGV는 좌석 선택 화면(개별 좌석 위치) 조회에 **회원 로그인을 요구**한다. 로그인 자동화는
이 프로젝트가 다루지 않으므로, 정확한 좌석 위치 대신 "잔여석 비율"로 근사 판단한다:
인기 상영관은 중앙 블록 좌석부터 먼저 팔리는 경향이 있어, 잔여석 비율이 낮을수록 남은
좌석이 가장자리/맨 앞줄일 가능성이 높다는 경험칙이다. `good_seat.min_free_ratio`(전체 좌석
대비 잔여 비율) 이상일 때만 "괜찮은 자리" 알림을 보내며, `good_seat.enabled: false`로 끄면
기존 방식(좌석이 1석이라도 남으면 즉시 알림)으로 되돌아간다.

## 설치

```bash
cd odyssey-kr
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## 텔레그램 봇 설정 (직접 해야 하는 부분)

1. 텔레그램에서 [@BotFather](https://t.me/BotFather)와 대화해 봇 토큰 발급
2. `.env`의 `TELEGRAM_BOT_TOKEN`에 토큰 입력
3. (선택) 본인을 최초 구독자로 등록하려면: 봇에게 아무 메시지나 보낸 뒤
   `python get_chat_id.py`로 chat_id를 확인해 `.env`의 `TELEGRAM_CHAT_ID`에 입력.
   등록되면 `config.yaml`의 `watch` 값을 본인의 기본 감시 조건으로 사용한다.
   생략해도 되며, 그 경우 아래 "구독하기"만으로 각자 조건을 설정하면 된다.

### 구독하기 (누구나, 대화형)

봇에게 메시지를 보내면(또는 `/start`) 아래 순서로 물어본다:

```
👋 알림 받을 조건을 설정할게요.
🎬 오디세이 (IMAX관)
📍 CGV 용산아이파크몰

감시를 시작할 날짜를 입력해주세요 (예: 2026-08-20)
> 2026-08-20
감시를 종료할 날짜를 입력해주세요 (예: 2026-08-25)
> 2026-08-25
감시할 시작 시각을 입력해주세요 (24시간제, 예: 09:00)
> 09:00
감시할 종료 시각을 입력해주세요 (예: 22:00)
> 22:00

✅ 설정 완료! 아래 조건에 맞는 자리가 나오면 알려드릴게요.
```

형식이 잘못되면(예: 날짜가 `YYYY-MM-DD`가 아니거나 종료일이 시작일보다 빠름) 같은 질문을
다시 하며, 답할 때까지 다음 단계로 넘어가지 않는다.

- `/start` — 새로 등록하거나 기존 조건을 다시 설정(덮어쓰기)
- `/status` — 현재 등록된 조건 확인
- `/stop` — 구독 해지
- 영화/상영관/극장은 개인이 고를 수 없다 — 전원이 `config.yaml`의 값을 공유하고, **날짜·시간대만** 개인화된다.
- 봇이 5초(`poll.subscriber_poll_seconds`)마다 새 메시지를 확인하므로 응답이 거의 즉시 온다.
- 구독자별 조건은 `subscribers.json`에 로컬로만 저장되며 git에는 올라가지 않는다.

## 설정 (`config.yaml`)

```yaml
theater:
  site_no: "0013"            # CGV 용산아이파크몰
  name: "CGV 용산아이파크몰"

movie:
  match: ["오디세이"]         # 영화명 부분일치, 여러 개 등록 가능

screen:
  match: ["IMAX관"]           # 상영관명 부분일치, 비우면([]) 전체 상영관

watch:
  # 구독자별 날짜/시간대는 텔레그램 /start로 각자 설정한다.
  # 아래는 최초 구독자(.env의 TELEGRAM_CHAT_ID)의 기본값으로만 쓰인다.
  start_date: "2026-08-22"
  end_date:   "2026-08-22"
  start_time: "09:00"
  end_time:   "22:00"

good_seat:
  enabled: true             # false면 좌석 1석이라도 있으면 즉시 알림(기존 방식)
  min_free_ratio: 0.12      # 전체 좌석 대비 잔여 비율이 이 값 이상이면 "괜찮은 자리"

poll:
  interval_seconds: 1.0
  jitter_seconds: 1.0
  subscriber_poll_seconds: 5  # 새 구독/해지 메시지를 확인하는 주기

alerts:
  repeat_minutes: 5           # 좌석이 남아있는 동안 재알림 주기
  heartbeat_minutes: 60       # 정상 작동 알림 주기
```

다른 극장을 감시하려면 `site_no`를 바꿔야 한다. CGV 사이트에서 극장 선택 시
`/api/v1/booking/searchRegnList?coCd=A420` 응답의 `siteNo` 값을 확인하면 된다.

## 실행

```bash
python watcher.py
```

크래시 시 자동 재시작하며 상시 실행하려면:

```bash
./run.sh
```

맥이 절전 모드로 들어가면 폴링이 멈추므로, 상시 감시가 목적이면:

```bash
caffeinate -s ./run.sh
```

## 주의사항

- **알림은 "예매창이 열렸다"는 신호일 뿐, 좌석을 잡아주지 않는다.** 인기 상영관은
  오픈 즉시 매진되므로 알림을 받으면 최대한 빨리 직접 예매해야 한다.
- 1초 폴링도 Cloudflare 차단 위험을 완전히 없애지는 못한다. 403/429가 감지되면
  자동으로 백오프(점진적으로 대기 시간을 늘림) 후 복구를 시도한다.
- 감시 대상 날짜에 해당 영화/상영관이 아예 편성되지 않을 수도 있다. 봇은 편성이
  뜨는 즉시 감지하지만, 편성 자체를 보장하지는 않는다.
- **"괜찮은 자리" 판정은 정확하지 않다.** 실제 좌석 위치는 CGV 로그인 후에만 볼 수 있어
  잔여석 비율로 근사할 뿐이다. 확실한 판단이 필요하면 알림을 받은 즉시 직접 좌석 배치를
  확인해야 한다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `watcher.py` | 메인 루프 (날짜 합집합 순환 폴링, 백오프, 하트비트, 구독자 폴링) |
| `cgv.py` | curl_cffi 기반 CGV API 클라이언트 |
| `notifier.py` | 텔레그램 전송, "괜찮은 자리" 근사 판정, 구독자별 맞춤 발송/중복 억제 |
| `subscribers.py` | 구독자별 날짜/시간대(WatchPrefs) 저장, `/start` 대화형 등록·`/status`·`/stop` |
| `config.py` | `config.yaml` + `.env` 로딩/검증 |
| `get_chat_id.py` | chat_id 확인용 1회성 헬퍼(선택) |
| `config.yaml` | 영화/상영관/극장 전역 설정, good_seat 임계값 |
| `subscribers.json` | 구독자별 감시 조건 (로컬 전용, git 미포함) |
| `run.sh` | 크래시 시 자동 재시작 래퍼 |
